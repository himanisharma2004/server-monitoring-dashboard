# Virtual Server Monitoring Dashboard

## Project Overview
This project builds a data engineering pipeline to monitor server performance and visualize key metrics using Power BI.

The system ingests raw server logs, processes and transforms the data using Python, and generates a monitoring dashboard for performance analysis.

## Tools & Technologies
- Python
- Pandas
- Power BI
- GitHub

## Project Structure
CSV Dataset
   ↓
Python Ingestion Script
   ↓
Data Cleaning & Transformation
   ↓
Processed Dataset
   ↓
Power BI Dashboard

## Data Pipeline

1. **Data Ingestion**
   - Load raw server monitoring data
   - Validate dataset structure

2. **Data Transformation**
   - Clean data
   - Generate performance metrics
   - Aggregate server statistics

3. **Dashboard Visualization**
   - CPU utilization trend
   - Server health distribution
   - Top servers by CPU usage
   - Key performance indicators (CPU, Memory, Disk)

## Key Dashboard Metrics
- Average CPU Utilization
- Average Memory Usage
- Average Disk IO
- Server Health Status

Power BI dashboard provides a monitoring view of server performance and system health.
